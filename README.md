# Blank App Structure

This is a blank application template with all the allowed file types:

## Allowed File Types

1. **HTML** - `index.html` (Main HTML file)
2. **JavaScript** - `scripts/main.js` (Main JavaScript file)
3. **CSS** - `styles/main.css` (Main CSS file)
4. **PGML** - `scripts/utils.pgml` (Podemos Generar Markdown Language)
5. **JSON** - `data/sample.json` (Data file)
6. **SVG** - `assets/logo.svg` (Scalable Vector Graphics)
7. **LESS** - `styles/components.less` (CSS preprocessor)
8. **SCSS** - `styles/variables.scss` (Sassy CSS)
9. **PHP** - `scripts/backend.php` (Backend script)
10. **Image Formats**:
    - JPG - `assets/sample.jpg`
    - JPEG - `assets/sample.jpeg`
    - PNG - `assets/sample.png`
    - GIF - `assets/sample.gif`
    - WebP - `assets/sample.webp`

## Usage

This structure provides a foundation for building applications with all the allowed file types. Each file type serves a specific purpose:

- **HTML**: Structure and content
- **CSS/SCSS/LESS**: Styling and presentation
- **JavaScript**: Client-side interactivity
- **PHP**: Server-side processing
- **JSON**: Data storage and exchange
- **SVG**: Vector graphics
- **Image files**: Raster graphics in various formats
- **PGML**: Custom markup language for documentation

## Notes

- All files are placeholders and can be expanded based on project requirements
- The PHP backend script can be accessed via a web server that supports PHP
- SCSS and LESS files would need to be compiled to CSS in a real application
- Image files are represented as text placeholders in this template
